# ESPBOY / ESP-S2

[PlatformIO](https://platformio.org) and [Wokwi](https://marketplace.visualstudio.com/items?itemName=wokwi.wokwi-vscode) Espboy project example

## Building

Install [PlatformIO](https://platformio.org) and open console

```
pio run
```

## Simulate the project

Install [Wokwi for VS Code](https://marketplace.visualstudio.com/items?itemName=wokwi.wokwi-vscode). Open the project directory in Visual Studio Code, press **F1** and select "Wokwi: Start Simulator".
